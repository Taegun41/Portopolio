[박태건 포트폴리오 - 실행 방법]

1. Node.js 20 이상을 설치합니다. (https://nodejs.org)
2. 압축을 푼 폴더에서 터미널(명령 프롬프트)을 열고 아래 명령을 차례로 입력합니다.

   npm install
   npm run dev

3. 브라우저에서 http://localhost:5173 에 접속합니다.
